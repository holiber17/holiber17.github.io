Tienda virtual de maquillaje

Paula's Store, Caracas

Tienda online para un negocio que vendía solo por Instagram y WhatsApp. El cliente arma su carrito, paga con el método que prefiera y el pedido llega a WhatsApp con el código y el total en dólares y bolívares.

  • Tasa del BCV automática con fuente de respaldo
  • Panel de administración protegido con Auth0 y rol de administrador
  • Métodos de pago editables: Pago Móvil, Zelle, Binance Pay, transferencia y efectivo
  • Carga de comprobantes y fotos de productos en Supabase Storage
  • C# / .NET
  • Entity Framework
  • PostgreSQL (Supabase)
  • Auth0
  • Render
  • Brevo

App para tablet que funciona como caja registradora: toma pedidos, cobra en tres monedas y descuenta el stock al vender. Avisa antes de que se acabe un producto.

  • Alta de productos escaneando el código de barras con la cámara
  • Alertas de stock bajo y agotado
  • Historial de movimientos y reportes de ventas
  • JavaScript
  • HTML / CSS
  • Supabase
